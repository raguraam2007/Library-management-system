# Library Management System

## About the Project

The Library Management System is a simple C++ project designed to manage books in a library. It helps users add books, view available books, search for books by title or author, and manage book issuing and returning.

This project was developed to understand the concepts of structures, file handling, and menu-driven programming in C++.

## Features

* Add new books to the library
* Display all books
* Search for books by title or author
* Issue books to users
* Return issued books
* Save book details using file handling

## Technologies Used

* **Programming Language:** C++
* **Concepts:** Structures, Functions, File Handling
* **Compiler:** GCC / MinGW

## How to Run

1. Download or clone this repository.

2. Open the project folder in VS Code or a terminal.

3. Compile the C++ program:

   ```bash
   g++ -std=c++14 library_management.cpp -o library_management.exe
   ```

4. Run the program on Windows:

   ```powershell
   .\library_management.exe
   ```
